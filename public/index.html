Konfigurasi Google OAuth

Masukkan Google OAuth 2.0 Client ID & Secret untuk menghubungkan login Google langsung dari aplikasi.

  1. Buka Google Cloud Console → Credentials
  2. Buat OAuth Client ID (Type: Web application atau Desktop app)
  3. Tambahkan Redirect URI:
    http://localhost:3000/auth/callback
